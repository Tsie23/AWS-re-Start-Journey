**Group Project 1: Building a Static Website for a Restaurant and Presenting AWS Migration Benefits**

## Project Summary: The Digital Leap for a Local Eatery

This project involved addressing the operational challenges of a real-world local restaurant, we called "Ember & Co", which was struggling to manage a high volume of customer bookings and orders manually. The manual system often led to confusion and errors, like mixed-up orders and double-booked tables.

The core task was to:
1. **Develop a simple static website** to streamline customer interactions, allowing them to place orders and make bookings online.
2. **Prepare a presentation** to convince Embre & Co's owner(s) of the significant benefits, cost savings, and specific services of migrating the restaurant's new digital presence to Amazon Web Services (AWS).

### Project Objectives and Goals

The primary goals of this project were to deliver a solution that directly addressed the restaurant's inefficiencies and to professionally advocate for cloud adoption:

1. Improve Operational Efficiency: Create a static website with user-friendly features like a booking form and an order submission form to reduce manual errors, such as order mix-ups and double bookings.
2. Establish an Online Presence: Build a fully functional static website for the restaurant and ensure it is hosted on AWS.
3. Demonstrate AWS Expertise: Recommend and explain the AWS services that best meet the restaurant's needs, specifically using Amazon S3 for website hosting and image storage.
4. Justify Cloud Migration: Create a persuasive presentation covering the restaurant's existing challenges, a comprehensive cost analysis (though not explicitly detailed in the document, it is a component of the presentation), and the overall benefits of moving to AWS.


### Step-by-Step Guide for Project Completion

The project was executed by delivering two main components: the Static Website and the AWS Presentation.

#### Phase 1: Building and Deploying the Static Website

1. Created a simple, user-friendly static website design for Ember & Co, focusing on simple, clean design, minimal colors for text readability while incorporating engaging elements like images. Included essential customer interaction features, such as a *booking form*, an *order submission form*, and a *confirmation page*.

3. Migrated the website to AWS S3 for hosting and storing website assets and images (like menu photos or restaurant ambiance), then linked the S3 bucket to AWS Cloudfront for global content distribution through secured protocol.

4. Host on AWS: Deployed the fully functional static website, hosting it using the recommended AWS service, Amazon S3.

### Reflection

I have learned that a simple static website, combined with cloud hosting, can dramatically solve real-world business problems like confusion and errors caused by manual processes. The project demonstrates that the first step to cloud migration doesn't need to be complex; a basic, well-designed online system can drive immediate efficiency gains.

Through my contribution to the project, which was handling the actual migration of the website by creating the S3 bucket and Cloudfront connection, I gaining valuable hands-on experience by practically using Amazon S3 to host a functioning website.
