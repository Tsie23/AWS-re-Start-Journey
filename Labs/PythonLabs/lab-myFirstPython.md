# Networking Lab: VPC Labs 

## Objective
- Write and execute "Hello, World", using Python 3.

## Steps Taken
1. Accessed the AWS Management Console and navigated to the Cloud9 IDE for the pre-configured reStart-python-cloud9 environment.

2. Created a new Python file within the IDE using File > New From Template > Python File.
![alt text](<images/Screenshot 2025-11-30 050306.png>)

3. Saved the file as hello-world.py in the /home/ec2-user/environment directory.
![alt text](<images/Screenshot 2025-12-09 164906(1).png>)

4. Opened a new terminal session within the Cloud9 IDE.
![alt text](<images/Screenshot 2025-11-30 181958.png>)

5. Confirmed the Python version to ensure we were running the correct syntax by using python3 --version.
![alt text](<images/Screenshot 2025-12-09 164925.png>)

6. Wrote the core program by entering the single line of code print("Hello, World") into the hello-world.py file.
![alt text](<images/Screenshot 2025-12-09 164925(1).png>)

7. Saved file then executed the script by clicking the Run (Play) button in the IDE menu bar, and verified the output in the bottom console pane, which successfully displayed the message "Hello, World".
![alt text](<images/Screenshot 2025-12-09 164906.png>)

## Challenges
- I struggled to run the "Hello World" code in the text editor and terminal due to incorrect syntax. I utilized the text editor syntax in the terminal code, and the terminal code syntax on the text editor. I resolved this by taking note of the error messages for both terminal and text editor output, which highlighted my error of misplaced parenthesis(); i.r.: not having the code inside parenthesis() on the text editor code syntax, and having the code wrapped in parenthesis() in the terminal. Once corrected the code executed successfully.

## Takeaways
I gained foundational experience working with the Cloud9 IDE, which simplified the development workflow by combining a text editor, a project file structure, and a terminal environment which provided immediate code execution and verification.
