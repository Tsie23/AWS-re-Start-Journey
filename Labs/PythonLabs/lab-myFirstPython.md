# Networking Lab: VPC Labs 

## Objective
- Write and execute "Hello, World", using Python 3.

## Steps Taken
1. Accessed the AWS Management Console and navigated to the Cloud9 IDE for the pre-configured reStart-python-cloud9 environment.
2. Created a new Python file within the IDE using File > New From Template > Python File.
3. Saved the file as hello-world.py in the /home/ec2-user/environment directory.
4. Opened a new terminal session within the Cloud9 IDE.
5. Confirmed the Python version to ensure we were running the correct syntax by using python3 --version.
6. Wrote the core program by entering the single line of code print("Hello, World") into the hello-world.py file.
7. Saved the file using File > Save.
8. Executed the script by clicking the Run (Play) button in the IDE menu bar.
9. Verified the output in the bottom console pane, which successfully displayed the message "Hello, World".

## Challenges
- Forgot to open port 22 in the security group
- Solved by editing the inbound rules
